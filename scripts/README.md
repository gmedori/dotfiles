# Scripts

This is a repo to track changes on all my local scripts and automations that I write.

## Organization

- Anything that runs a Keyboard Maestro script and does nothing else goes into the `Keyboard Maestro` directory.
- Applescripts that are just automation tools for other scripts go in the `applescripts` directory.
- Smaller scripts are written in Bash and/or Perl and those go straight into the `bin` directory.
- Larger command line tools are written in Go. The source for those files goes into `src` with the compiled binaries going in `bin`.
